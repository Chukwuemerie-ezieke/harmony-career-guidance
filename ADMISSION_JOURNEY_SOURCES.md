# PathVerge Admission Journey Planner

## Purpose and Scope
This document outlines the purpose of the `ADMISSION_JOURNEY` data and logic within PathVerge. The planner is a public, browser-local tool that helps Nigerian students track a practical route through JAMB preparation, UTME, Post-UTME, JAMB CAPS, and admission/clearance.

## Nature of the Tool
- This is purely a planning and checklist tool. It is **not an admissions authority**.
- Following this checklist or marking tasks as complete **does not guarantee admission** to any institution.
- All tasks utilize cautious language to reflect the unpredictable nature of admission cycles.

## Official Resources
Students are strongly encouraged to verify all information directly with official authorities:
- **JAMB Official Website:** https://jamb.gov.ng
- **JAMB IBASS:** https://jamb.gov.ng/ibass
- **JAMB e-Facility / CAPS:** https://efacility.jamb.gov.ng

## Data Storage
- To protect user privacy, the Admission Journey Planner is completely client-side.
- Data (such as completed tasks, optional UTME scores, and pathway selections) is stored solely in the user's browser `localStorage`.
- No planner data is transmitted to or stored on any PathVerge server.

## Maintenance and Updates
- Content must be reviewed before each admission cycle to ensure it aligns with the latest processes from JAMB and major Nigerian universities.
